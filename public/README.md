# Public Assets Directory

Place your custom media files (images, audio files, video files, fonts) in this `public` folder.

Files added here will be served directly from the root URL.
For example:
- A file placed at `public/my-wedding-photo.jpg` can be referenced as `/my-wedding-photo.jpg`
- A file placed at `public/music.mp3` can be referenced as `/music.mp3`

You can also paste image or audio URLs in the **Personalize** menu in the top right corner of the Save the Date application!
